# Factorio Tech Tree

[Explore Factorio’s technology tree](https://factorio-tech-tree.com/) and plan your next research, in the base game or Space Age.

![Space Age technology tree with Rail support foundations selected, all required research highlighted, and total science costs displayed](resources/sample_image.png)

## Features

- Switch between base Factorio 2.x and Space Age.
- Search technologies and filter by science packs.
- Inspect research costs, prerequisites, unlocks, and bonuses.
- Highlight the full prerequisite tree and see total science pack requirements.
- Pan, zoom, and revisit selections with back and forward navigation.
