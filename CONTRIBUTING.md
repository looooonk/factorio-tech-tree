# Contributing

Bug reports, suggestions, and pull requests are welcome.

- For bugs, include the game edition (base game or Space Age), steps to reproduce, and what you expected. Add a screenshot when it helps explain the issue.
- For suggestions, describe the problem the change would solve.
- For pull requests, keep changes focused, describe their purpose, and report what you verified. Include before-and-after screenshots for visual changes.

See the [development guide](docs/development.md) for setup, repository layout, checks, and deployment. Follow the repository’s [coding guidelines](AGENTS.md) and run the relevant checks before submitting code changes.

For updates to exported technologies or icons, follow the [game data guide](docs/game-data.md).
